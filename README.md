# AquaRoute — учебная верстка сайта водных прогулок

Проект создан как самостоятельная учебная верстка, ориентированная на структуру страницы маршрутов водных прогулок.

## Файлы

- `index.html` — основная HTML-страница
- `style.css` — стили и адаптивность
- `script.js` — мобильное меню, проверка формы, сохранение заявки в localStorage
- `database.sql` — пример структуры таблиц для базы данных

## Что есть в макете

- шапка сайта с меню;
- первый экран;
- блок описания маршрута;
- карточки маршрутов;
- карточки катеров и яхт;
- таблица прайс-листа;
- блок этапов бронирования;
- форма заявки;
- FAQ;
- адаптив под телефон.

## Как запустить

Открой `index.html` в браузере.
